# 🛒 SellingStringDataBot

Telegram-бот для автоматической продажи цифровых строк/ключей через CryptoBot.

Бот позволяет пользователю выбрать тариф, принять оферту, оплатить заказ и автоматически получить строки из `.txt` файла. Также в проекте есть админ-панель с управлением ценами, приветственным текстом, офертой, инструкцией и загрузкой новых строк.

---

## 🚀 Возможности

### 👤 Для пользователя

- запуск бота через `/start`;
- отображение приветственного текста;
- выбор тарифа:
  - 1 строка;
  - 10 строк;
- показ оферты перед оплатой;
- кнопка принятия оферты;
- создание ссылки на оплату через CryptoBot;
- проверка оплаты;
- автоматическая выдача строк после успешной оплаты;
- отправка инструкции после выдачи данных.

---

### 🛠 Для администратора

Администратор определяется по Telegram ID.

Админ-панель открывается автоматически для администратора после команды `/start`.

Возможности админки:

- просмотр статистики;
- просмотр остатка строк;
- изменение цены за 1 строку;
- изменение цены за 10 строк;
- изменение приветственного текста;
- изменение текста оферты;
- изменение инструкции;
- загрузка нового `.txt` файла со строками;
- закрытие админ-меню.

## 🤖 Где взять `BOT_TOKEN`

`BOT_TOKEN` — это токен Telegram-бота.

Чтобы его получить:

1. Откройте Telegram.
2. Найдите бота:

```text
@BotFather
```

3. Отправьте команду:

```text
/newbot
```

4. Укажите название бота.
5. Укажите username бота.
6. BotFather выдаст токен.

Пример токена:

```text
1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Его нужно вставить в `.env`:

```env
BOT_TOKEN=1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

---

## 💳 Где взять `CRYPTOBOT_TOKEN`

Для оплаты используется CryptoBot / Crypto Pay.

Чтобы получить токен:

1. Откройте Telegram.
2. Найдите бота:

```text
@CryptoBot
```

3. Перейдите в раздел:

```text
Crypto Pay
```

4. Создайте новое приложение.
5. Получите API Token.
6. Вставьте его в `.env`.

Пример:

```env
CRYPTOBOT_TOKEN=123456:AAxxxxxxxxxxxxxxxxxxxxxxxx
```

> ⚠️ Важно: `CRYPTOBOT_TOKEN` — это не токен от BotFather. Это отдельный токен из CryptoBot / Crypto Pay.

---

## 👑 Где взять Telegram ID администратора

Чтобы бот понимал, кто является администратором, нужно указать Telegram ID.

Узнать свой Telegram ID можно через одного из ботов:

```text
@GetMyIDBot
```

или:

```text
@userinfobot
```

После получения ID вставьте его в `.env`:

```env
ADMIN_IDS=123456789
```

Если админов несколько, укажите их через запятую:

```env
ADMIN_IDS=123456789,987654321
```

## 🔑 Файл со строками

Строки, которые бот будет выдавать после оплаты, хранятся в файле:

```text
data/keys.txt
```

Пример содержимого:

```text
LICENSE-7F2K-91AA-XP22
LICENSE-8K2A-11ZZ-LP90
LICENSE-PP22-AA11-ZX88
LICENSE-ABCD-1234-QWER
LICENSE-ZZ99-KK88-LL77
```

Каждая строка должна быть записана с новой строки.

После успешной оплаты бот выдаёт нужное количество строк и удаляет их из файла, чтобы они не повторялись.

## 📄 Оферта перед оплатой

Перед созданием счёта бот показывает пользователю текст оферты.

Пользователь должен нажать:

```text
✅ Принимаю
```

Только после этого бот создаст ссылку на оплату.

Если пользователь нажмёт:

```text
❌ Отмена
```

покупка будет отменена.

Текст оферты можно изменить через админ-панель.

## 🔁 Защита от повторной выдачи

В боте предусмотрена защита от повторной выдачи строк.

Если пользователь несколько раз нажмёт кнопку проверки оплаты по одному и тому же счёту, бот не выдаст новые строки повторно.

Это нужно для защиты от ситуации, когда один оплаченный счёт используется несколько раз.

## ❗ Возможные ошибки

### `Token is invalid`

Проверьте `BOT_TOKEN` в `.env`.

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

Убедитесь, что токен скопирован полностью и не содержит лишних пробелов.

---

### `CRYPTOBOT_TOKEN = None`

Значит `.env` не загрузился или токен написан неправильно.

Проверьте:

```env
CRYPTOBOT_TOKEN=ваш_токен_от_CryptoBot
```

Также убедитесь, что в проекте используется `load_dotenv()`.

---

### `unable to open database file`

Создайте папку:

```text
data/
```

Или убедитесь, что в `database.py` есть создание папки:

```python
os.makedirs("data", exist_ok=True)
```

---

### `Недостаточно строк в файле`

В файле `data/keys.txt` меньше строк, чем требуется для выбранного тарифа.

Например, пользователь выбрал тариф на 10 строк, а в файле осталось только 5.

Решение:

- загрузить новый `.txt` файл через админ-панель;
- или вручную добавить строки в `data/keys.txt`.

---

### Админ-меню не появляется

Проверьте, правильно ли указан Telegram ID администратора в `.env`:

```env
ADMIN_IDS=123456789
```

Если ID указан неверно, бот будет считать вас обычным пользователем.

## 🧩 Режим разработки

Для теста можно временно имитировать успешную оплату.

В обработчике проверки оплаты можно временно заменить:

```python
status = invoice["status"]
```

на:

```python
status = "paid"
```

После этого бот будет считать счёт оплаченным.

> ⚠️ После теста обязательно вернуть обратно:

```python
status = invoice["status"]
```
