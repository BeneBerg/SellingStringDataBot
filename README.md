# 🛒 SellingStringDataBot

Telegram-бот для автоматической продажи цифровых строк/ключей через CryptoBot / Crypto Pay.

Бот позволяет продавать цифровые строки из нескольких отдельных файлов, принимать оплату через CryptoBot, автоматически выдавать оплаченные строки пользователю и управлять товарами через админ-панель в Telegram.

---

## 🚀 Основные возможности

### 👤 Для пользователя

- запуск через команду `/start`;
- отображение приветственного текста;
- выбор раздела/товара для покупки;
- отдельные тарифы для каждого раздела: 1 строка и 10 строк;
- отображение цены прямо в кнопке покупки;
- проверка наличия строк до создания оплаты;
- показ общей оферты перед оплатой;
- кнопка принятия оферты;
- кнопка отмены покупки;
- создание счёта на оплату через CryptoBot;
- проверка оплаты;
- автоматическая выдача строк после успешной оплаты;
- отдельная инструкция после покупки для каждого раздела;
- защита от повторной выдачи по одному и тому же счёту.

### 🛠 Для администратора

Администратор определяется по Telegram ID из файла `.env`.

Админ-панель открывается автоматически для администратора после `/start` и отображается как нижнее меню Telegram.

Возможности админки:

- просмотр общей статистики;
- просмотр остатка строк по каждому разделу;
- загрузка строк в выбранный раздел;
- добавление строк к существующему файлу без перезаписи старых строк;
- очистка строк выбранного раздела с подтверждением;
- настройка цен для каждого раздела;
- изменение приветственного текста;
- изменение общей оферты;
- изменение отдельной инструкции для каждого раздела;
- управление несколькими реферальными ссылками;
- просмотр статистики по каждой реферальной ссылке;
- просмотр пользователей, пришедших по конкретной реферальной ссылке;
- просмотр покупок и суммы покупок конкретного пользователя;
- пагинация реферальных ссылок и пользователей.

## 🧩 Разделы продаж

В боте предусмотрена продажа строк из нескольких разных файлов.

Пример схемы:

```text
Раздел 1 → data/keys_1.txt
Раздел 2 → data/keys_2.txt
Раздел 3 → data/keys_3.txt
```

Каждый раздел имеет своё название, файл со строками, текст кнопок покупки, цены за 1 и 10 строк, а также отдельную инструкцию после покупки.

Оферта при этом общая для всех разделов.

Настройки разделов хранятся в файле:

```text
app/services/products.py
```

---

## 💰 Тарифы

Для каждого раздела доступны два тарифа:

```text
1 строка
10 строк
```

Цены задаются отдельно для каждого раздела и могут изменяться через админ-панель.

Пример кнопок для пользователя:

```text
💳 Купить 1 строку Мегафон (20 USDT)
💳 Купить 10 строк Мегафон (150 USDT)
```

Если администратор изменит цену, новая цена будет отображаться в кнопке при следующем открытии раздела.

---

## ✅ Проверка наличия товара

Перед созданием счёта бот проверяет количество строк в файле выбранного раздела.

Если строк нет, пользователь увидит сообщение:

```text
❌ В данный момент товар отсутствует
```

Если пользователь выбирает 10 строк, а в файле меньше 10 строк, бот не создаёт счёт и показывает сообщение о нехватке товара.

Дополнительная проверка также выполняется после оплаты, чтобы защититься от ситуации, когда товар закончился между созданием счёта и оплатой.

---

## 📄 Оферта

Перед созданием оплаты бот показывает пользователю общий текст оферты.

Пользователь должен нажать:

```text
✅ Принимаю
```

Только после этого создаётся счёт на оплату.

Если пользователь нажимает:

```text
❌ Отмена
```

покупка отменяется, а сообщение с офертой заменяется текстом отмены.

Текст оферты можно изменить через админ-панель.

---

## 📘 Инструкции после покупки

После успешной оплаты бот отправляет:

- название раздела;
- купленные строки;
- инструкцию для выбранного раздела.

У каждого раздела может быть своя отдельная инструкция.

Редактирование инструкций доступно в админ-панели.

---

## 🔗 Реферальная система

В боте реализована система нескольких реферальных ссылок.

Администратор может:

- открыть раздел рефералок;
- создать новую реферальную ссылку;
- листать реферальные ссылки страницами;
- смотреть статистику по каждой ссылке отдельно;
- смотреть пользователей, пришедших по конкретной ссылке;
- открывать карточку конкретного пользователя;
- смотреть количество покупок пользователя;
- смотреть сумму покупок пользователя.

Пример реферальной ссылки:

```text
https://t.me/YourBotUsername?start=partner_1712345678
```

---

## 📊 Что считается в реферальной статистике

Для каждой реферальной ссылки отображается:

- название рефералки;
- код ссылки;
- сама ссылка;
- количество уникальных пользователей, которые перешли по ссылке;
- количество покупок;
- общая сумма покупок;
- список пользователей с пагинацией;
- подробная карточка пользователя.

Если пользователь сделал покупки в разных разделах, они учитываются в общей реферальной статистике.

---

## 👥 Пользователи рефералки

Внутри конкретной реферальной ссылки администратор может открыть список пользователей.

Пользователи отображаются кнопками:

```text
@username
```

Если у пользователя нет username, используется имя. Если нет имени, отображается Telegram ID.

В карточке пользователя показывается:

- Telegram ID;
- username или имя;
- дата перехода по ссылке;
- количество покупок;
- сумма покупок;
- последние покупки.

## 🛠 Админ-панель

Админ-панель отображается как нижнее меню Telegram.

Основные разделы:

```text
📊 Статистика
🔗 Партнёрка
🛒 Разделы
📝 Тексты
📂 Загрузить строки
🔑 Остаток строк
🗑 Очистить строки
❌ Закрыть админку
```

### 📊 Статистика

Показывает общее количество пользователей и покупок.

### 🔑 Остаток строк

Показывает остаток строк по всем активным разделам.

Пример:

```text
🔑 Остаток строк по разделам:

Мегафон: 13
Йота: 25
Теле2: 8
```

### 📂 Загрузка строк

Позволяет загрузить `.txt` файл в выбранный раздел.

Логика работы:

```text
📂 Загрузить строки
↓
Выбор раздела
↓
Отправка txt-файла
↓
Строки добавляются в конец нужного файла
```

Файл не заменяется полностью. Новые строки добавляются к уже существующим.

### 🗑 Очистка строк

Позволяет очистить строки только в выбранном разделе.

Перед очисткой бот спрашивает подтверждение:

```text
✅ Да, очистить
❌ Отмена
```

### 🛒 Разделы

Открывает выбор раздела для настройки цен.

После выбора раздела можно изменить цену за 1 строку и цену за 10 строк.

### 📝 Тексты

Открывает настройки текстов:

- приветствие;
- общая оферта;
- инструкция для каждого раздела.

## 🗃 База данных

Бот использует SQLite.

Файл базы данных:

```text
data/bot.db
```

В базе хранятся:

- пользователи;
- покупки;
- настройки;
- созданные счета;
- статус выдачи товара;
- реферальные переходы;
- реферальные ссылки.

---

## 🔁 Миграции базы данных

База данных обновляется мягко, без удаления старых данных.

Используются безопасные операции:

```sql
CREATE TABLE IF NOT EXISTS ...
ALTER TABLE ... ADD COLUMN ...
INSERT OR IGNORE INTO settings ...
```

Это позволяет обновлять работающего бота без удаления `data/bot.db`.

---

## 🔁 Защита от повторной выдачи

Каждый счёт сохраняется в базе.

После успешной выдачи строк счёт помечается как выданный.

Если пользователь повторно нажмёт кнопку проверки оплаты по тому же счёту, бот не выдаст строки повторно.

## 🤖 Где взять BOT_TOKEN

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Создайте бота командой `/newbot`.
4. Скопируйте токен.
5. Вставьте его в `.env` как `BOT_TOKEN`.

---

## 💳 Где взять CRYPTOBOT_TOKEN

1. Откройте Telegram.
2. Найдите `@CryptoBot`.
3. Перейдите в раздел Crypto Pay.
4. Создайте приложение.
5. Скопируйте API Token.
6. Вставьте его в `.env` как `CRYPTOBOT_TOKEN`.

Важно: `CRYPTOBOT_TOKEN` — это не токен от BotFather.

## 🔑 Файлы со строками

Строки хранятся в отдельных файлах:

```text
data/keys_1.txt
data/keys_2.txt
data/keys_3.txt
```

Каждая строка должна быть с новой строки.

Пример:

```text
LICENSE-7F2K-91AA-XP22
LICENSE-8K2A-11ZZ-LP90
LICENSE-PP22-AA11-ZX88
```

Эти файлы не рекомендуется хранить в GitHub.

## ⚠️ .gitignore

В `.gitignore` обязательно должны быть:

```gitignore
.env
data/bot.db
data/keys.txt
data/keys_1.txt
data/keys_2.txt
data/keys_3.txt
__pycache__/
*.pyc
venv/
.venv/
```

Если `.env`, база или файлы строк уже были добавлены в Git, нужно убрать их из отслеживания:

```bash
git rm --cached .env
git rm --cached data/bot.db
git rm --cached data/keys.txt
git rm --cached data/keys_1.txt
git rm --cached data/keys_2.txt
git rm --cached data/keys_3.txt
```

После этого сделать коммит и push.

## 🔄 Запуск 24/7 через systemd

Создайте файл:

```bash
nano /etc/systemd/system/sellerbot.service
```

Пример содержимого:

```ini
[Unit]
Description=SellingStringDataBot Telegram Bot
After=network.target

[Service]
WorkingDirectory=/root/SellingStringDataBot
ExecStart=/root/SellingStringDataBot/venv/bin/python /root/SellingStringDataBot/main.py
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
```

Применить:

```bash
systemctl daemon-reload
systemctl enable sellerbot
systemctl start sellerbot
systemctl status sellerbot
```

```python
status = invoice["status"]
```

```python
status = "paid"
```


## ❗ Частые ошибки

### Token is invalid

Проверьте `BOT_TOKEN`.

### CRYPTOBOT_TOKEN = None

Проверьте `.env` и наличие `load_dotenv()`.

### unable to open database file

Проверьте, что существует папка `data/`.

### Недостаточно строк

В выбранном файле строк меньше, чем нужно для покупки. Добавьте строки через админ-панель.

### Раздел не найден

Проверьте, что `product_code` совпадает в `products.py`, `callback_data` и базе данных.

Лучше использовать единый формат:

```text
product1
product2
product3
```

### Git pull не проходит из-за .env или keys

Сделайте резервную копию:

```bash
cp .env ../env_backup.txt
cp data/keys_1.txt ../keys_1_backup.txt
cp data/keys_2.txt ../keys_2_backup.txt
cp data/keys_3.txt ../keys_3_backup.txt
```

Потом устраните конфликт или уберите файлы из Git.
